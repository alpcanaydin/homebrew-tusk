# Homebrew tap for Tusk

[Tusk](https://github.com/alpcanaydin/tusk) is a fast, native, keyboard-driven database client for macOS.

```sh
brew install alpcanaydin/tusk/tusk
```

Update with `brew upgrade tusk` (Tusk also updates itself in the app).

The cask in `Casks/tusk.rb` is updated automatically by Tusk's release workflow.
